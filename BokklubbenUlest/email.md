# Hovedformål
Lage en enkel og brukervennlig nettside hvor du og dine venner kan foreslå bøker, stemme over hvilken bok som skal leses, og avtale bokmøter.

# Kjernefunksjoner

1. Forslag til bøker
    -Du og medlemmene kan legge inn forslag til bøker å lese.

    -Hvert forslag inneholder: navn, forfatter, kort beskrivelse, lenke (til hvor boka kan kjøpes/lånes) og bokcover.

    -Mulighet for kommentarer på hvert forslag.
    
    -“Tommel opp / tommel ned”-funksjon for avstemming.

    -Vise hvem som har likt hva.

    -Klikk på et forslag for å se mer informasjon om boken.

2. Brukerinteraksjon
    -Ingen åpen registrering – kun innlogging for medlemmer (opprettes av admin).

    -Bruker kan ha profil med navn og etternavn (evt. avatar – valgfritt, ikke ekte profilbilde).

    -Egen profilside viser:

    -Bøker man har lest

    -Favorittbøker

3. Møteplanlegging
    -Administrator kan foreslå dato for neste bokmøte.

    -Medlemmer kan krysse av om de kan komme eller ikke.

4. Design
    -Varmt, høstlig uttrykk med fokus på enkelhet og brukervennlighet.

# Aklaringer:
    -Innlogging: Admin legger til og redigerer brukere. Men registrerte brukere bør også få redigere seg selv.

    -Profil: Litt personlig info, liste med bøker.
    Hvis tid; legge til bok for avstemning fra sin liste

    -Avstemming: Får stemme på 2 bøker. Tidsfristen skal være på en uke eller mindre. Admin starter og avslutter avstemningen.
    Mulig auto start hvis det er foreslått 5 bøker?

    -Rating: 1-5 stjerner

    -Navn: Bokklubben Ulest
